## 🇧🇷 Português

Vitta Online é uma aplicação Flutter moderna projetada para simplificar a gestão de clínicas e o agendamento de profissionais de saúde.

### Status Atual do Projeto
Atualmente, o sistema conta com as seguintes funcionalidades implementadas:
-   **Autenticação Completa:** Login e gerenciamento de perfil via Supabase.
-   **Gestão de Plantões:** Acompanhamento e organização de turnos e escalas.
-   **Chat em Tempo Real:** Comunicação fluida entre a equipe e profissionais.
-   **Painel Administrativo:** Controle total sobre as configurações da clínica, gestão de profissionais e dados dos usuários.
-   **Integração com Supabase:** Banco de dados em tempo real, autenticação e armazenamento de arquivos.

### Tecnologias Utilizadas
-   **Framework:** Flutter (Android/iOS/Web/Windows)
-   **Backend:** Supabase (Auth, Postgres, Real-time, Storage)
-   **Gerenciamento de Estado:** Flutter Riverpod
-   **Navegação:** GoRouter
-   **Estilização:** Google Fonts & Design System customizado

### Como Usar
1.  Certifique-se de ter o **Flutter SDK** instalado.
2.  Clone o repositório:
    ```bash
    git clone https://github.com/playedu1/vittaonline.git
    ```
3.  Configure as variáveis de ambiente no arquivo `.env` ou em `lib/config/supabase_config.dart`.
4.  Execute a instalação das dependências:
    ```bash
    flutter pub get
    ```
5.  Inicie a aplicação:
    ```bash
    flutter run
    ```

## 🇺🇸 English

Vitta Online is a modern Flutter application designed to simplify clinic management and healthcare professional scheduling.

### Current Project Status
The system currently features the following implemented functionalities:
-   **Full Authentication:** Login and profile management via Supabase.
-   **Shift Management:** Tracking and organization of shifts and schedules.
-   **Real-time Chat:** Fluid communication between teams and professionals.
-   **Admin Panel:** Full control over clinic settings, professional management, and user data.
-   **Supabase Integration:** Real-time database, authentication, and file storage.

### Technologies Used
-   **Framework:** Flutter (Android/iOS/Web/Windows)
-   **Backend:** Supabase (Auth, Postgres, Real-time, Storage)
-   **State Management:** Flutter Riverpod
-   **Navigation:** GoRouter
-   **Styling:** Google Fonts & Custom Design System

### How to Use
1.  Ensure you have the **Flutter SDK** installed.
2.  Clone the repository:
    ```bash
    git clone https://github.com/playedu1/vittaonline.git
    ```
3.  Configure your environment variables in `.env` or in `lib/config/supabase_config.dart`.
4.  Run the dependency installation:
    ```bash
    flutter pub get
    ```
5.  Start the application:
    ```bash
    flutter run
    ```
