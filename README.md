# VittaOnline

## Project Description
VittaOnline is a comprehensive health management application built with Flutter. The application is designed to assist users in managing their health records, scheduling appointments, and tracking various health metrics seamlessly.

## Features
- **User Registration and Authentication**: Secure sign-up and login process for users.
- **Health Records Management**: Users can store and manage their health records securely.
- **Appointment Scheduling**: Users can schedule and manage appointments with healthcare providers.
- **Health Metrics Tracking**: Track metrics such as blood pressure, glucose levels, and more.
- **Notifications**: Reminders for appointments and medication schedules.

## Tech Stack
- **Frontend**: Flutter, Dart
- **Backend**: Firebase, REST APIs
- **Database**: Firestore, Firebase Realtime Database
- **State Management**: Provider, Bloc

## Setup Instructions
1. **Clone the repository**: 
   ```bash
   git clone https://github.com/playedu1/vittaonline.git
   cd vittaonline
   ```
2. **Install Flutter SDK**: Follow the instructions on the [Flutter official website](https://flutter.dev/docs/get-started/install).
3. **Install Dependencies**: Run
   ```bash
   flutter pub get
   ```
4. **Run the Application**: Use the following command:
   ```bash
   flutter run
   ```

## Platform Support
- **Android**: Supports Android 5.0 and above.
- **iOS**: Supports iOS 11.0 and above.
- **Web**: Accessible via modern web browsers.
